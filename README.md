# ImprintCap-ASM
ASM analysis for Imprint Disorders

Allele‑specific methylation (ASM) analysis pipeline for targeted bisulfite sequencing of human imprinting control regions (ICRs/DMRs). The pipeline links heterozygous SNPs to nearby CpGs at imprinted loci and quantifies allele‑specific methylation for each sample.
